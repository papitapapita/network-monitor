## How to Update This Index

When creating a new requirement:
1. Add entry to "Requirements by Status" (under Planned)
2. Add entry to appropriate "Requirements by Sprint"
3. Add entry to appropriate "Requirements by Epic"
4. Add entry to appropriate "Requirements by Bounded Context"
5. Add entry to appropriate "Requirements by Priority"
6. Update "Quick Stats"
7. Update "Last Updated" date at top

When updating requirement status:
1. Move entry to new status section
2. Update sprint allocation if changed
3. Update story points if estimated
4. Update "Quick Stats"
5. Update "Last Updated" date
